## About

I've been writing software since middle school, beginning with creating Minecraft mods. I'm currently an intern at Federated Hermes doing data engineering work and other internal tooling. My primary interests are fintech / backend development, and I'm currently looking for internship opportunities for summer 2027. Outside of tech I'm into geography, football, chess, and lifting.

I'm also the founder of [Keygrad](https://www.keygrad.com), which maps 43,000+ course equivalencies across 1,800+ colleges into 14 Pennsylvania universities.
